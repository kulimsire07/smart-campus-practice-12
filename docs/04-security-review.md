# Security Review Checklist & Audit (Task #07 — Lecture #12 & OWASP Alignment)

## 1. Scope & Ethical Testing Rule
- **Audited Systems:** Code-Based Smart Campus Checker (GitHub Pages) and Low-Code Smart Campus Checker (Appsmith Cloud Free).
- **Authorization Boundary:** All dynamic checks (DAST perspective) were limited to **safe manual input tests on our own deployed instances**. No automated scanners or unauthorized security probes were run against Appsmith Cloud, GitHub, or any third-party service.

## 3. AI-Agent Security Controls (Lecture #12)
1. **Least Privilege:** No AI assistant was given GitHub write tokens, Appsmith account credentials, or connector access; all edits were manually reviewed before committing.
2. **Untrusted External Content:** Prompts and AI-generated code were treated as untrusted until manually audited for unsafe DOM sinks or logic flaws.
3. **Secret Hygiene:** Zero personal credentials, tokens, or private workspace keys were shared in prompts or exposed in submitted screenshots.
4. **Reproducible Verification:** Every functional claim and security statement was independently verified via live execution (`T1–T8`) and browser inspection.
